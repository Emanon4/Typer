## Main scene prompt

Create an original, highly detailed front-facing vintage mechanical typewriter scene for an interactive writing website. Use the supplied reference only for composition, warm mood, and physical proportions. The machine is black enamel with aged brass rims, round glass keycaps, a visible typebar fan, platen, carriage, return lever, and side knobs. Place it on a walnut table against a dark umber wall with a blank ivory sheet. Use a symmetrical 1536 × 1024 composition. Include no people, cursor, text, key legends, branding, watermark, or UI.

Output: `public/assets/typewriter-with-paper.png`.

## Source-extracted paper bail

`public/assets/paper-bail-reference.png` is a 1510 × 40 transparent crop of the exact horizontal guide rod and two rubber rollers shown in the user's source screenshot. `scripts/extract-paper-bail.py` records the alpha-mask extraction. This asset is positioned as carriage hardware rather than drawn with CSS, and it travels horizontally with the physical carriage while remaining vertically fixed to the platen.

As of 2026-09-07 the close-up renders the rubber rollers as proportional CSS background crops from this unchanged asset, joined by an independent CSS metal rod. The assembly shares the paper carriage displacement. This avoids flattening the entire strip to fit the measured gap between printed rows; the photographed machine itself remains unchanged.

## Reference-matched writing assets

`public/assets/reference-paper-stock.png` is a clean paper-stock crop from the user-supplied video and is the default selected stock. `public/assets/paper-stock-real-v2.png` remains available as the higher-fiber alternative.

`public/assets/SpecialElite-Regular.ttf` and `public/assets/SpecialElite-LICENSE.txt` come from the official Google Fonts repository. Special Elite matches the Latin type slugs visible in the supplied video; the app self-hosts it so the effect does not depend on a remote font request.

`public/assets/audio/` contains eight individual key strikes plus space, carriage return, and eject samples cut from the supplied video. `scripts/extract-reference-audio.sh` records the source timecodes and can reproduce those assets from the original MP4.

Chinese and Latin output are rendered one glyph at a time by `src/InkGlyph.jsx`. Each glyph receives deterministic pressure variation, ribbon-thread dropout, small missing-ink areas, a rare weak strike, and occasional double-impact offset. Latin uses Special Elite; Chinese uses a Song-style metal-type face and the identical ink-transfer model.

### 2026-09-22 legible ribbon impressions

The user rejected both blurred, obstructed text and the overly clean vector-only correction. `src/inkTypography.js` now describes each glyph's seeded pressure, irregular fiber voids, slight ink spread and small alignment variation. `src/InkGlyph.jsx` renders that impression as scalable text with a luminance mask; PNG export paints the same normalized paths at final resolution.
