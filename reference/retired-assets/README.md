# Retired assets

Historical images that the app no longer loads. They are kept for provenance
(see `ASSET_NOTES.md` and the dated design notes in `docs/`) but live outside
`public/`, so they are not shipped in the Sites or GitHub Pages builds.

- `desk-*.png`: the retired writer's-desk scenes (night lamp, morning study,
  rainy midnight × three finishes).
- `typewriter-base.png`, `typewriter-with-paper.png`, `paper-texture.png`:
  first-iteration machine and paper renders.
- `reference-machine-body-v1.png`, `reference-carriage-v1.png`: rejected
  whole-machine candidates; do not restore them as the active close-up.
