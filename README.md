# Typer

让你情不自禁地开始写作！

[在线使用](https://emanon4.github.io/Typer/) · [公开源码](https://github.com/Emanon4/Typer)

Typer 是一个支持系统中文输入法的写实机械打字机。按键会推动字车，回车触发真实机械音并让稿纸逐行上卷，退格只回退字车而不擦除已经落下的铅字，退纸后可查看、保存和导出完整稿纸。

产品专注于全屏机械打字机。在「工作台」中可分别选择机型与配色，选择会随本地稿件保留。原作家书桌模式及场景切换已经撤下；此前使用书桌模式的页面会直接进入机械打字机。

默认的「原片米白」复现参考视频的纸色、宽度、初始露纸高度和压纸尺；「稿纸箱」还提供纤维象牙、民国书简、红格稿纸和蓝线信纸。所选纸张会被记住，并同时用于实机纸面、退纸预览和 2480 × 3508 PNG 导出。

中文与英文共用逐字墨迹模型，保留轻微压力差和纸张纤维造成的细小缺墨。屏幕使用可缩放字形，PNG 在最终分辨率重绘同一组墨迹，避免模糊与重影。色带仅在击打时抬起，停笔后整行文字完整露出。机械音效从用户提供的参考视频中逐项取样。

工作台增加「凯鲁亚克」长卷：连续进纸，没有页末。收卷会存入文稿箱，之后可展开、续写或导出连续 PNG 压缩包；单张散页仍导出 2480 × 3508 PNG。

带后端运行时，顶部「信邮」可领取 `名字@typer` 站内邮址，选信笺写信，贴邮票后投给另一个账号。默认每天寄 3 封、至少等待 24 小时；可在邮局设置调整。未寄草稿不限封数；送达、每日限额和访问权限由服务端控制。GitHub Pages 只运行前端，线上版明确显示「线上邮局尚未开通」；完整账号与投递代码已包含在本仓库，可通过下方 Node 服务运行。

开发需要 Node.js 22.13+（使用内置 SQLite）：

```bash
npm ci
npm run dev
```

生产验证：

```bash
npm run build
npm run test:sites
npm test
npm start
```

GitHub Pages 由 `.github/workflows/pages.yml` 在每次推送 `main` 后自动发布。工作流先运行完整构建和测试，再用 `npm run build:pages` 输出到 `dist/pages`。发布仅上传该静态目录，不包含数据库。`npm run build` 继续保留原 Sites 构建契约。

`npm start` 在 127.0.0.1:8787 同时提供构建后的界面和邮局 API。数据库保存在 `.typer-data/post.sqlite`；账号数据保留在本机。部署配置与边界见 [长卷与信邮说明](docs/scroll-and-post-design-2026-09-22.md)。Sites 静态 Worker 未接入此数据库，单独发布静态页面不提供跨账号通信。

机械特写的「工作台」分别提供机型与配色：经典开放式保留描线漆壳与外露机构，旅行便携式使用弧面包覆机壳和皮纹提手，编辑室事务机使用拱形铸壳与铆接铭牌。三款都使用金属包边的旧式圆键，磨损纹理仅附着于各自零件表面。五种配色可用于每款机型，选择会被记住。机型切换保留当前稿纸和字车位置。

本地开发服务器的 `/qa/variants.html` 是独立的机械遮挡验收页，可冻结击打、满页和退纸姿态，并运行三款机型与五种配色的 7920 帧像素检查，同时检查整行字迹和回车杆的连续连接。该入口不进入生产构建。

视觉资产、生成提示和来源边界见 `ASSET_NOTES.md`，设计对照和交互验证见 `design-qa.md`。
