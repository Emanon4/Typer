# 打字机中文字形：京华老宋体

用户指定只更换打字机印在纸上的汉字，不改变应用按钮和标题字体。实时纸面、成稿预览、已存稿件、收件阅读与 PNG 导出均通过 `inkTypography` 使用同一字体。中文全角标点也使用京华老宋体。

- SHA256：`35d92af5ac4e9485e8e7749098e67211da5885d2697d95aea979fe4acd19ee2a`。
- 字重：Regular 400，取消原中文字体的模拟加粗。
