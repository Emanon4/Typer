## 已落地

机身不再依赖生成的整机候选图。按原帧测量键帽中心与机身轮廓，字杆左右各八根，每根有独立起点。被选中的字杆离开自身槽位，到同一固定落字点，再回落；每次绘制中仅出现一次。键帽有独立下压。

纸张、压纸杆、滚筒及两端旋钮位于同一个横移容器；回车时同一 A4 纸上移一个从行距导出的距离，回车杆同时运动。字杆抬起、落墨、字车步进使用同一组时序常量。没有通过裁切整机照片制造运动。

新英文稿采用视频的大字与 56 px 逻辑行距；以中文起笔的稿纸保持 33 行紧凑排版。旧稿按既有紧凑排版恢复；每张纸的排版标识随稿件保存。实时纸张、成稿预览及 PNG 导出使用相同坐标与墨迹绘制函数。

## 实测

Safari 中验证了英文连续输入、回车换行、中文粘贴后逐字落墨、刷新恢复、退格保留墨迹、退纸成稿，以及保存和重新打开中英文文稿。通过页面按钮导出了 PNG，重新打开确认尺寸和墨迹。测试在独立 4174 来源进行；原页面未加入测试文案。最后关闭临时标签页，Safari 留在原 4173 地址。

`npm run build` 和 34 个 Node 测试通过，包含 14 个 IME 事件顺序测试、固定落字点/行距/压纸杆间距的几何检查及击打时序。Sites 打包文件存在，受保护的托管文件未改动。

## 五项视觉检查与证据边界

- 字体：英文纸面使用 Special Elite，中文使用宋体；键帽标识已与独立键面共同绘制，不再依赖生成图片中的字。数字键副标与 Shift 字距按原帧修正，但未证明全部字形逐像素相同。
- 布局：并排画面中机身轮廓、各行键位和浅纸条位置一致；场景铺满视口，没有侧边黑栏。
- 颜色：保留黑色机身、黄铜边缘和暖棕背景。原视频的局部模糊、高光和材质变化未达到逐像素一致。
- 图像：移动部件已改为独立实时绘制；纸面使用原有纹理，房间背景继续使用独立房间资产。
- 内容：保持 Typer 名称和指定口号，未复制源品牌或水印，原稿存在。
