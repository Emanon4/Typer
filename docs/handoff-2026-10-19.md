3. **跑一遍基线**：`npm ci`，然后 `npm run build`、`npm test`、`npm run build:pages`，确认全部通过（截至本文 69/69）。注意要先构建再跑测试。

5. **部署邮局 Worker**（用户还没做，见第 5 节第 1 条）：
   ```bash
   cd post-worker
   npx wrangler login   # 已登录可跳过；也可以用 CLOUDFLARE_API_TOKEN
   npx wrangler deploy
   ```
   本轮没有改数据库结构，不需要 `npx wrangler d1 migrations apply`。部署后打开 https://typer-post.moji-pet.workers.dev/api/health ，返回 `{"ok":true,...}` 即成功。部署包已用 `npx wrangler deploy --dry-run` 离线打包验证过：37.7 KiB，绑定 D1 `typer-post` 和 `ALLOWED_ORIGINS=https://emanon4.github.io`，包含本轮的服务端改动。
6. **检查 Worker 的 CPU 用量**（见第 5 节第 2 条），之后再考虑改动注册或登录流程。
7. **问用户还没定的事**：字体要不要转 WOFF2（第 5 节第 3 条）。
8. **工作方式**：从 `main` 新建分支开发，用 PR 合并。PR 上会有 Devin 自动评审，它的意见要先对照代码核实再处理。用户习惯在 PR 里用中文沟通。

## 2. 本轮改了什么

### 存储与文稿
- 所有 `localStorage` 读写都经过 `src/safeStorage.js`（`readStored` / `writeStored` / `removeStored`）。存储写满或被禁用时，字照常落纸，状态栏显示 `STORAGE_FULL` 提示，直到下一次保存成功。
- 文稿箱（散页和长卷）全部存进 IndexedDB，逻辑在 `src/manuscriptStore.js`。旧版存在 `localStorage` 里的散页稿（`typer-manuscripts-v1` / `lead-typewriter-manuscripts-v1`），启动时由 `migrateLegacyManuscripts` 迁移一次，保留原保存时间，迁完删掉旧键。
- 文稿可以删除：查看稿件时点「删除」，再点「确认删除，无法恢复」。
- 长卷：一卷只保留一份存档。工作副本的 `archiveId` 指向它的存档，再次收卷时覆盖同一份。换新卷或续写别的卷前，`retireActiveScroll` 先把当前卷存档，再删掉它的工作副本。
- 活动长卷编号存在 `localStorage`（`typer-active-scroll-v1`）。编号丢失或失效时，`latestWorkingScroll` 回退到 IndexedDB 中最近更新的未归档长卷。

### 打字队列
- 一次粘贴或输入法提交最多打出 2000 字（`src/typingInput.js` 中的 `MAX_PASTE_GRAPHEMES`），超出部分会提示。
- Esc 由全局监听处理：先清空待打队列，再关闭最上层的抽屉（工作台、稿纸箱、文稿箱、稿件查看页）。
- 退纸、换纸、切换写作模式、续写长卷、取信笺时，先 `stopTyping()` 停下队列，再用 `holdInput()` 锁住输入，换稿完成后才恢复。换稿期间写作模式按钮禁用。
- 打印键长按不连发；退格和空格只在机器空闲时才接受连发（`acceptsKeyRepeat`）。

### 性能与发布包
- 京华老宋体（36MB）不再在打开页面时下载，改为由 `ensureInkFont` 在开始用中文输入法、即将落下中文字或导出时才加载。
- 发布包从 99MB 降到 68MB：退役图片移到 `reference/retired-assets/`（见该目录 README），山路、归燕两枚邮票改为 `public/assets/stamps/*.webp`。
- 导出 PNG 时复用同一个画布。
- 邮局 `/api/letters` 列表不再读取整封信的快照，邮票 ID 用 `json_extract(snapshot,'$.stampId')` 取得。
- Pages 前端在本标签页没有登录凭证时，不再请求线上 `/api/me`。

### 其他
- 修正邮址规则的错误提示；README 更新了纸张列表和测试顺序说明；`verify.yml` 的 actions 锁定到具体提交。

## 3. 关键结构速查

| 位置 | 内容 |
| --- | --- |
| `src/App.jsx` | 主组件，约 1300 行：打字队列、换稿流程、各抽屉与弹窗 |
| `src/documentStore.js` | IndexedDB `typer-documents-v1`：`documents`（元数据）和 `lines`（按 `[documentId, index]` 逐行存） |
| `src/manuscriptStore.js` | 文稿箱：列表、存档、删除、迁移、`latestWorkingScroll` |
| `src/safeStorage.js` | `localStorage` 保护层 |
| `src/typingInput.js` | 粘贴上限、按字素切分、长按规则 |
| `src/inkTypography.js` / `src/InkGlyph.jsx` | 墨迹字形与按需加载字体 |
| `src/exportPaper.js` | 2480 像素宽 PNG 和 ZIP 导出 |
| `server/post-service.mjs` | 邮局逻辑，本地 SQLite 与线上 D1 共用 |
| `post-worker/` | Cloudflare Worker 入口与 D1 迁移 |

`localStorage` 里只放小偏好和当前散页草稿：`typer-draft-v1`、`typer-sound-v1`、`typer-paper-v1`、`typer-sheet-paper-v1`、`typer-writing-mode-v1`、`typer-active-scroll-v1`、`typer-machine-model-v1`、`typer-machine-finish-v1`、`typer-preferred-stamp-v1`、`typer-stamp-collection-v1`。以 `lead-typewriter-` 开头的是旧名，读到时会迁移到新名。信邮的登录凭证放在 `sessionStorage`，只在当前标签页有效。

## 4. 怎么验证

```bash
npm ci
npm run build        # Sites 打包测试要检查 dist/，所以先构建
npm run test:sites
npm test
npm run build:pages  # Pages 构建，base 为 /Typer/
npm run dev          # 本地开发，同时提供本地邮局 API
```

改到打字、换稿或存储时，单元测试不够，要在浏览器里实测：
- 英文和中文都能落纸，京华老宋体能加载。
- 退纸、存入文稿箱、导出 PNG（2480 × 3508）、删除都正常。
- 长卷连续收卷、续写、换卷后，IndexedDB 里每卷只有一份存档，没有遗留的工作副本。
- 粘贴长文时 Esc 能停下；换稿期间按键和模式按钮都被锁定。
- 机械遮挡相关的验收要求见 `AGENTS.md`。注意：README 提到的 `/qa/variants.html` 验收页不在仓库里，`.gitignore` 排除了 `/qa/` 目录，它只存在于原作者本机。需要的话得重新做一个。

PR 上会有 Devin 自动评审。它提的问题要先对照代码核实再处理，其中有一条已由用户裁定为设计如此（见第 6 节）。

## 5. 待办与待决

### 需要在 Cloudflare 上操作
1. **重新部署邮局 Worker**：在 `post-worker/` 运行 `npx wrangler deploy`，本轮的列表查询优化和提示修正才会上线。不部署也不影响使用，新旧版本兼容。
2. **检查 Worker 的 CPU 用量**：口令加密用 scrypt（N=32768），每次注册或登录约耗 50–100ms CPU，Workers 免费套餐每次请求只给 10ms。去后台看注册、登录有没有超时失败。改哈希算法必须配合已有账号的迁移，否则老账号会登录失败。

### 等用户拍板
3. **字体格式**：京华老宋体授权写明不得修改后再分发，所以不能裁剪子集。转成 WOFF2 能明显变小，但是否算「修改」要用户决定。
4. **注册验证码**：目前每个 IP 15 分钟内可尝试注册或登录 40 次。出现批量注册时再加 Cloudflare Turnstile。

### 可以做，不急
5. 旧版本留下的长卷工作副本还在 IndexedDB 里，不显示，只占空间。清理有误删风险，目前不动。
6. `src/App.jsx` 偏大，以后改到哪块再顺手拆出去，不要一次性大重构。机械时序、输入法事件和存储顺序缠在一起，大改容易回归。
7. 文稿和其他弹窗目前没有锁定键盘焦点，只在打开时聚焦到关闭按钮，背后的写作台设为 `inert`。

## 6. 已定的设计决定
- 删除一卷的存档时，如果这卷还装在打字机上，再收卷会重新存档，文稿箱里会再出现一份。删除的只是存档，不会丢弃机器上的长卷。
- 粘贴上限 2000 字；Esc 停止待打文字；打印键不连发。
- 以上两条也记在了 `AGENTS.md` 里。
