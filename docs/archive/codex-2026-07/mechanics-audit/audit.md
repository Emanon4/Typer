# Typer 拟真机械审计

审计日期：2026-07-29。审计对象为当前 `649b937` 版本，核心任务是从键盘输入中文、看到字键与字锤动作、完成回车进纸。证据来自用户本轮提供的两张截图，以及本轮在 Codex 内置浏览器中重新复现和保存的截图。

## 总判断

当前实现可以保留为静态视觉概念，但不适合作为最终机械运行层。问题已经超出 CSS 微调范围：打字机、纸张、压纸杆、油墨和字锤并不共享一个物理状态或三维空间，只是多张图片和 DOM 图层按百分比移动。只要出现击键、回车、换机型或视口变化，遮挡关系就会破裂。

建议停止继续扩展这套二维机械动画，保留写作数据、中文输入、稿纸箱、文稿箱和导出逻辑；机械表现层改为「Blender 建模与绑定＋浏览器实时 3D」。不建议此阶段改用 Unreal Engine 5。

## 审计步骤

1. 作家书桌空闲态——一般。`01-desk-before-input.png` 显示静止时照片质感成立，环境、材质和构图有沉浸感。然而纸张已经烘焙在场景图中，无法真正进纸、退纸或更换纸型。
2. 单次击键——失败。`02-typebar-strike.png` 复现了击键瞬间的穿模。代码从整张场景照片裁出楔形区域并旋转；所谓字锤会携带原照片中的机身、阴影和边缘，覆盖静态底图。用户截图 `05-user-typebar-penetration.png` 反映的是同一结构问题。
3. 回车与纸张进给——失败。用户截图 `06-user-paper-occlusion.png` 中，文字基线穿过压纸杆和橡胶轮；纸张下缘、油墨和硬件遮挡没有共同的击打线。机械特写中程序纸张、独立压纸杆图片和底图各自使用百分比坐标，误差会随行数和视口累积。
4. 场景与机型切换——需要重做。书桌模式为每个场景和机型生成一张独立照片，却只为每个场景保存一组纸张、字锤和按键坐标；不同机型几何略有变化，覆盖层不会随模型关节自动对齐。机械特写还固定使用黑色机身，因此已选象牙白机型切换进去后会变回黑色。

## 根因证据

- `src/App.jsx:311-329` 用多边形裁切整张照片模拟字锤轨道。
- `src/App.jsx:900-913` 和 `src/App.jsx:1135-1147` 再次加载完整场景或机身图片，作为击打动画覆盖层。
- `src/App.jsx:861-898` 的书桌纸张实际上只显示油墨；照片里的纸完全静止。
- `src/App.jsx:1085-1133` 的机械特写把纸张和压纸杆拆成独立图层。
- `src/deskScenes.js:5-33` 依靠人工百分比标定场景；机型变体没有独立机械几何。

## 建议架构

Blender 中先只制作一台完整机器，每个可动件必须是独立对象并有真实转轴：键帽、键杆、字锤、字篮、色带升降器、字车、滚筒、压纸杆、回车杆、棘轮和铃。先完成一颗键到纸面的完整因果链，再复制和绑定其余键。

浏览器保留现有 React 写作外壳，使用 Three.js 加载 Blender 导出的 GLB。所有动作由一个机械状态机驱动：按键角度决定连杆和字锤角度；字锤到达击打点后才写入油墨；字车由棘轮步进；回车同时复位字车并旋转滚筒。纸张是一张绕滚筒弯曲的网格，油墨写入纸张 UV 对应的动态 CanvasTexture，因此不存在 DOM 纸面与机器分离的问题。

书桌环境可以继续使用摄影背景或 HDRI，第一阶段没有必要把书、烟灰缸和房间全部建模。先让机器和纸正确，之后再决定是否将桌面道具三维化。多机型也应推迟；先通过一套机械骨架，再做材质皮肤，最后才做结构不同的机型。

Unreal Engine 5 只有在决定发布原生桌面应用，或者接受云端 GPU 加 Pixel Streaming 的部署成本时才值得采用。当前产品是浏览器写作工具，UE5 会增加安装体积、输入法桥接、部署和服务器成本，却不会自动解决机械结构错误。

## 中文真实性边界

西文篮式打字机无法机械地容纳任意中文字符。若保留当前西式机器和系统中文输入法，产品能做到的是「机械运动和纸面反馈真实，中文字模由数字适配器在击打瞬间替换」，这在视觉与触觉上可以可信，但不是历史真实。若要求历史机制也真实，则必须另建真正的中文打字机，例如字盘式机器或明快打字机的检字结构；它的操作方式不会是当前 QWERTY 机器。

## 可访问性与证据边界

现有输入框、按钮标签、状态播报和减少动态效果支持是有效基础。书桌控制文字在暗背景上偏小且对比度低，仍需键盘焦点与缩放实测。本轮确认的是结构性视觉故障；没有测试屏幕阅读器，也没有对每一种机型、纸型和浏览器尺寸做完整矩阵回归。

## 验收门槛

首个 3D 技术样机只需一台机器、一个场景和一张 A4 纸，但必须连续输入 200 字、回车 20 次、慢放检查字锤且零穿模；击打点、油墨落点、压纸杆和滚筒始终处于同一坐标；切换视口时只改变相机，不重新标定机械部件。达到这些条件后，再迁移完整中文写作和文稿功能。
