# Typer Model 01 reference set

Typer Model 01 uses a 1924 Underwood Model No. 5 as an engineering and proportion reference. The finished Typer asset keeps its own branding and adds a hidden digital type-slug adapter for Chinese output.

Museum record: https://collections.museumsvictoria.com.au/items/388645

Reference facts used in the model:

- Overall dimensions: 390 mm wide, 320 mm deep, 250 mm high.
- Platen width: 252 mm.
- Forty-two typebars in a curved horizontal basket.
- Front-strike visible writing line, vertical ribbon spools, four-row keyboard.
