| 问题 | 实施结果 |

## 剩余难点与下一步

**首先拆分夜灯木桌的照片资产。** 本轮通过界面选择红格稿纸后，在近景可以看到红格，切到书桌仍是白纸。书桌 CSS 隐藏纸材、只移动油墨；纸张和压纸杆都在整张照片里。应从夜灯黑漆这一组开始，制作干净底图、独立纸面/遮罩和前景硬件，复用本轮的纸车与送纸模型。以换纸后纸材真实可见、纸和压纸杆同步、无接缝且活动行无遮挡为验收条件，再扩展其他场景。

**完成一台机器的视觉验收。** 当前滚轮已保持比例，但紧行距使可用硬件高度很小；正常视图中的尺寸感与字杆运动仍要对照参考视频逐帧审查。不能仅因包围盒不相交，就认定机械外观完全拟真。冻结摄影机身继续作为基准，现阶段不需要引入新的三维整机外观。

**补真实系统输入法和成稿一致性。** 实测 macOS 拼音候选窗、连续选词、取消组词及长段输入；再检查实机、成稿预览和导出的排版与油墨一致性。输入事件去重已解决可证明的问题，系统输入法这一层仍未验证。
